# Student Attendance Management System

# Project Overview
The Student Attendance Management System is a Python-based desktop application developed using Tkinter and MySQL. It helps manage student records and track attendance efficiently.

# Technologies Used
- Python
- Tkinter
- MySQL
- mysql-connector-python

## Features
- Add Student
- Search Student
- Update Student Details
- Delete Student
- Mark Attendance
- View Today's Attendance
- Monthly Attendance Report
- Batch-wise Attendance Report
- Attendance Percentage
- Parent Details Management

# Project Structure
- Student_Attendance_Management.py
- requirements.txt
- README.md

# Installation

1. Clone this repository.
2. Install required packages:

   `pip install -r requirements.txt`

3. Create the required MySQL database and tables.
4. Configure your MySQL credentials.
5. Run the Python file:

   `python Student_Attendance_Management.py`
